# Git Collaboration

- Working Directory vs Staging vs History
	Working Directory -> Folder on computer hard drive where you view, create, and edit project files. Represents current, real time state of your files.
	Staging -> Draft area where git prepares and organizes chnages that you want to include in your next commit. Allows you to choose which file updates are ready to be commited. 
	History -> Git's permanent database stored in .git folder. Contains the entire timeline of the projects past versions. When you commit, Git takes a snapshot of the files and logs them to to the timeline. Allows you to view past changes, track progress, or roll back to a previous save point.
- Branching Rules
	Experiment on new feature branches and only merge when it is safe to do so.
	Peer code reviews -> code merges cannot be approved until enough people have confirmed that it is okay to do so.
	Block force pushes
- Pull Request Expectations
	Write clear descriptions about what changed, why, and how to test it.
	Keep PRs small and scoped
	Review PRs quickly to reduce blocking progress
	Give good feedback
